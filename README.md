# Intelligent-OS Field Audit

**Live dossier:** https://lucface.github.io/intelligent-os-field-audit/

On 2026-07-22 a one-person "Intelligent OS" (the whole operating layer one builder runs around his AI tooling: memory with provenance, retrieval, skills, agents, scheduled autonomy, evals, security rails, business integration) audited itself against **G-Brain**, **Hermes Agent**, and **OpenClaw** across 12 dimensions, closed its biggest measured gap the same day, and re-graded itself that night. The dossier is the record: interactive charts, logic trees, a receipts-first scorecard, and the before/after ghost race.

## Audit your own system

[`prompt.md`](./prompt.md) is a paste-in prompt for Claude Code (best on Fable/Opus, max effort). It inventories what actually exists on your machine, scores the same 12 dimensions with receipts, calibrates against the same reference field, and renders you a dossier of your own.

**Post your scorecard as an [issue](https://github.com/Lucface/intelligent-os-field-audit/issues/new?template=scorecard.md)** — the issue tracker is the leaderboard.

## Method rules

1. Receipts before scores — inventory by looking, not by asking.
2. Measured beats claimed — a ledger number outranks an architecture that "should" work.
3. N/A is never zero — out-of-scope-by-design is graded N/A, excluded from lead counts.
4. No flattery — every trailing dimension is classified CHOSEN (deliberate) or EARNED (real gap + smallest closing artifact).
5. Zero-regression honesty — re-grades never silently lower a score.

Scores and rival receipts are date-stamped **2026-07-22** (public repos, release ledgers, published security research). Stars and versions drift fast; the shapes drift slowly. Not affiliated with any of the three projects.
